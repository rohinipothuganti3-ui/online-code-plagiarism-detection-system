# Online Code Plagiarism Detection System

## 📌 Project Overview

A web-based system designed to detect similarities between submitted source codes and help identify potential code plagiarism.

## 🎯 Objective

To compare source-code submissions and calculate their similarity, making it easier to identify copied or highly similar code.

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- SQL

## ✨ Features

- User login and authentication
- Code submission
- Code similarity detection
- Similarity results
- Database management
- Simple and user-friendly interface

## ⚙️ How It Works

1. User logs into the system.
2. User submits source code.
3. The system processes the submitted code.
4. Submitted code is compared with existing submissions.
5. Similarity is calculated.
6. The result is displayed to the user.
